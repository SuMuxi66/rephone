## 目标

1. **P1**：出售订单支付从硬编码 mock 闭环切换到与维修线同源的 `PaymentService` 统一入口——生产未配置微信支付时 fail-closed（50012），本地开发用 `WXPAY_MOCK=true`（dev profile）保留 mock 闭环。
2. **P2**：重试 admin `vite build`（环境问题，尽力验证）。
3. **P3**：回收订单列表时间格式化（小程序 + 管理端），对齐维修/出售列表。
4. **P4**：`chalk` 补进 devDependencies、迁移 `wx.getSystemInfoSync`。

## 非目标

- 真实微信支付联调（无商户号环境）；回收打款链路；快递100 真实轨迹。
- admin 构建环境问题的根修（杀软配置属用户机器操作，本轮只重试验证）。
