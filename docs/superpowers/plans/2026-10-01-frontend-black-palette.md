# 前端改造：炭黑 + 赤陶配色体系 + 首页去 AI 味（2026-10-01）

> **状态：已完成（2026-10-01）。** 执行结果见文末「## 11. 实际结果」。

## 1. 目标

1. 全仓配色从 v4「科技蓝 + 橙」换成 **v5「炭黑 + 赤陶」**（用户已从三套方案中选定 C）
2. 顺手修掉两笔历史债：**v3 暖灰中性色残留** 与 **裸写色值违规**
3. `pages/home` 做「去 AI 味」减法：5 档字号、3 种圆角、去掉全屏卡片化、打破三等等分

## 2. 非目标

- 不改业务逻辑、不改接口、不改数据模型
- 不改回收/维修/购买的流程页结构
- 不引入 UI 组件库

## 7. 阶段二：318 处硬编码 → `var(--token)`

**这一步才是重头。** 不做的话，页面里会残留蓝/橙/暖灰，换色等于没换干净。

映射规则（按色系分类，逐个复核）：

| 色系 | 处理 |
|---|---|
| 蓝系（`#1A5CE8` `#0091FF` …） | → `var(--brand)` / `var(--brand-deep)` / `var(--brand-light)`，按原明度就近归位 |
| v3 暖灰（`#10201C` `#F6F4EF` `#99A39D` `#5D6A64`） | → `var(--text-1)` / `var(--bg-page)` / `var(--text-3)` / `var(--text-2)` |
| 橙系（`#FA550F` `#D05B27` `#E17349` `#FFECE9` …） | → `var(--accent)` / `var(--accent-deep)` / `var(--accent-light)`；**涉及价格的改 `--money`** |
| 中性灰（`#DDDDDD` `#F2F2F2` …） | → `var(--border-light)` / `var(--line-strong)` / `var(--bg-page)` |
| 红（`#FF2525` `#ED3427`） | → `var(--danger)`（**先看上下文确认是错误态**） |
| `#FFFFFF` | 保留（卡片白） |
| 模板遗留（`#FFF185` 等） | 逐个看用途，能删则删 |

**必须逐文件 diff 复核**：318 处里一定有语义色被误判的风险（尤其红/黄）。

## 8. 阶段三：`pages/home` 去 AI 味

参考产出：`docs/design/2026-10-01-home-palette-c.html`（完整首页预览）。

| 项 | 现状 | 改为 |
|---|---|---|
| 字号档数 | **12 档**（44/40/34/30/27/26/24/23/22/21/20/19） | **5 档**：44 / 32 / 28 / 24 / 20 rpx |
| 圆角种类 | **9 种**（999/16/50%/28/18/12/10/8/0 0 16 0） | **3 种**：`--radius-card` / `--radius-sm` / `999rpx` |
| 信任条 | 浅蓝卡 + 5 个勾圆圈 | **一行纯文字**（3 项），无容器无图标 |
| 三大入口 | 三张完全等分的卡 | **1 大 2 小**：卖旧机横向大卡 + 修/买两张小卡 |
| Banner | `linear-gradient(135deg, …)` ×3 | **纯色 + 大几何圆**，不用默认渐变角 |

**核心原则：让一屏里出现「不装东西的地方」。** 全屏都是圆角卡 = AI 味的来源。

## 10. 风险

1. **语义色误判**：318 处里的红/黄必须逐个看上下文，不能按色系批量替换
2. **重构未定型**：zcode 的性能重构可能再次调整这些文件的路径或结构，阶段二必须**以重构后的最新路径为准**重新盘点，不能直接用本文件的 40 个路径
3. **提交混入**：任何时候都要 `git commit -- <显式路径>` + `git show --stat` 复核
4. **浅色底对比度**：赤陶 `#B4530F` 在白底上的对比度约 4.3:1，价格是加粗大字没问题；如果发现小字用赤陶，要改用 `--text-1`

### 与计划的差异
1. **基数变了**：计划按 318 处 / 40 文件；重构后实测 **700 处 / 63 文件**（含模板分包 473 处）。
   模板分包原不在计划内，但它是购买主路径（货架 / 商品详情 / 下单），必须一起换。
2. **多修了三个计划外的问题**（都在执行中发现）：
   - **TDesign 组件一直在用默认蓝 `#0052D9`**：`theme.wxss` 用 `.t-button { --td-* }` 类名覆盖，
     而 app.wxss 对自定义组件无效 → 声明形同虚设。改挂 `page` 后才真正生效。
   - **自定义 tabBar 激活态一直是默认蓝**：它渲染在 page 节点树之外，继承不到 `page` 令牌。
     这大概率就是「橙色蓝色配色很奇怪」里那个持续存在的「蓝」。
   - **`app.json` tabBar 的 `selectedColor` 还是 v3 深松绿**（app.json 用不了 CSS 变量，历次换色都漏）。
3. **踩到一个新坑**：WXSS 不支持 `*` 选择器，写了会让 `app.wxss` 编译失败并**拖垮整个项目构建**
   （全页白屏 + 自动化取不到页面）。已写入 AGENT.md §5 禁止清单。
