# 首页改版设计 v3（深松绿方向）

日期：2026-09-30 ｜ 分支：feature/recycle-mvp ｜ 状态：**版式已落地**（配色已全局应用）
落地实现：pages/home/home.{js,wxml,wxss}
可视化设计稿：docs/design/2026-09-30-home-redesign-v3.html（浏览器打开；URL 加 #full 为整页长图模式）
静态长图：docs/design/2026-09-30-home-redesign-v3.png
**取代 v2**：docs/superpowers/specs/2026-09-30-home-redesign-v2.md（暖橙模板风，用户反馈「AI 味重」）

## 1. v2 的问题（自我批评）

1. **渐变头 + 每块圆角白卡 + 统一阴影** —— Tailwind/shadcn 模板的默认长相，没有取舍就没有风格。
2. **橙色铺满**：头部渐变、CTA、价格、标签底色全是同一橙的浓淡，等于没有主次。
3. **粉彩圆形图标 + 居中文字**：五个一模一样的圆，是「自动生成」最典型的痕迹。
4. **每一块都是卡片**：卡片不是设计而是偷懒的分组；页面没有发丝线、没有留白节奏。
5. **信息权重无差别**：维修/回收/购买三块一样大，等于让用户自己猜哪个重要。

## 2. 配色：从「促销橙」换成「工具感的深松绿」

橙色是二手平台的通用色（转转、爱回收），语义是热闹与低价；而 RePhone 要卖的是
**「先报价、修好再付、有质检报告」** —— 这是专业与可信，不是折扣。深松绿同时命中三件事：
回收/环保、质检通过、工具与可靠，并与所有竞品拉开距离。

| 令牌 | 值 | 用途 |
|---|---|---|
| --pine-deep | #0A3D30 | 头部实底（主色·深） |
| --pine | #0E5A47 | 选中态 / 强调 / 主按钮文字色 |
| --pine-tint | #E8F0ED | 极少量浅绿底（徽标） |
| --money | #B86A0E | **只用于钱**（价格、回收价） |
| --paper | #F6F4EF | 页面暖白纸底 |
| --ink | #10201C | 正文墨色（非纯黑） |
| --line | #E7E4DC | 发丝线，替代投影 |

**硬规则**：一屏内深绿只出现在头部与选中态；琥珀只出现在「钱」上；其余交给暖白与墨色。
颜色越少，越像被设计过。

## 3. 版式原则（去卡片化）

- 去掉全部投影，改用 1px 发丝线 + 8~10px 小圆角；硬边比浮起更「专业」。
- 不用胶囊搜索框，改成一条带下边线的通栏，弱化 App 感。
- 故障入口改**描边方框**（图标统一 1.7px 墨色描边），不用粉彩圆底。
- 三业务改「目录」分栏（01/02/03 + 竖线），比三张并排卡更有秩序、更省高度。
- 严选改「1 张大卡 + 2 行紧凑列表」的不对称结构 —— 第一件商品值得放大，其余降级为列表。
- 回收改**行情表**（品牌 / 机型 / 最高价，细线分栏），信息密度匹配「比价」心智。
- 保障降为一行小字，不再占一个宫格区块。

## 4. 字阶与数字

| 层级 | 字号/字重 | 用途 |
|---|---|---|
| claim | 27px / 700，字距 -0.6 | 头部主张「修好，再付钱。」 |
| title | 17px / 700 | 区块标题 |
| body | 13px / 400，行高 1.7 | 说明文案 |
| label | 10.5px / 600，字距 .14em | 品牌名、编号（APPLE / 01） |
| price | 23px / 800 | 价格 |

所有金额使用 `font-variant-numeric: tabular-nums` 等宽数字，列表金额才能上下对齐 —— 
这是「看起来专业」成本最低的一招。

## 5. 与 v2 的差异对照

| 维度 | v2 | v3 |
|---|---|---|
| 主色 | 橙 #FF5F15 + 满屏浅橙 | 深松绿 #0A3D30，浅绿仅用于选中态 |
| 头部 | 橙渐变铺满 | 深绿实底，无渐变 |
| 卡片 | 全部圆角白卡 + 阴影 | 发丝线 + 小圆角，几乎无阴影 |
| 价格色 | 与品牌同色 | 独立琥珀色，只出现在钱上 |
| 三业务 | 三张等宽卡 | 目录式分栏 01/02/03 |
| 严选 | 三张等宽卡横滑 | 1 张大卡 + 2 行紧凑列表 |
| 回收 | 机型小卡横滑 | 行情表 |
| 保障 | 四宫格圆形图标 | 三行小字 |

## 6. 落地方式（建议两个提交）

1. `feat(design): 设计令牌切换为深松绿体系` —— 改 `style/design-tokens.wxss` 的 `--brand` 等令牌。
   注意这是**全局换肤**，维修/回收/购买/我的各页都会跟着变，所以单独一个提交，便于回退。
2. `feat(home): 首页改版 v3` —— 按本稿重写 `pages/home/home.{js,wxml,wxss}`，
   `home.js` 需增加严选商品拉取（复用已就绪的 `GET /api/wx/goods`）。

建议同时在 `AGENT.md` 增加一条设计约束：**价格一律使用 `--money`，禁止用品牌色写金额**。

## 7. 待用户确认

1. **主色方向**：深松绿（本稿）是否接受？备选可换深靛蓝（#12294B）——同样是「工具感」但更常见。
2. **是否接受全局换肤**：换肤会影响所有页面，不只是首页。
3. **文案**：头部主张「修好，再付钱。」与「哪里坏了」是否用这个口语化调性。
4. 首页数据：严选商品取几件、回收行情取几个机型（当前设计为 1+2 与 4 行）。

## 8. 落地后的验证方式

1. 微信开发者工具「清缓存后编译」，走查：头部、搜索、故障方框、三业务分栏、严选大卡与列表、行情表、保障小字、下拉刷新。
2. 各卡跳转与参数传递：行情行 → 回收估价 + 品牌预选；严选卡 → 商品详情（含质检报告页）。
3. 无库存 / 无热门机型时的降级：对应区块隐藏或空态，不出现空白卡。
