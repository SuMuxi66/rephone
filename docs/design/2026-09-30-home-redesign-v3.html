首页改版 v3 · 深松绿方向

2026-09-30 ｜ 替换 v2（暖橙模板风）｜ 状态：待确认

一、先承认 v2 的「AI 味」在哪

  • 渐变头 + 每块圆角白卡 + 统一阴影——这是 Tailwind/shadcn 模板的默认长相，没有取舍就没有风格。
  • 橙色铺满：头部渐变、CTA、价格、标签底色全是同一个橙的浓淡，等于没有主次。
  • 粉彩圆形图标 + 居中文字：五个一模一样的圆，是「自动生成」最典型的痕迹。
  • 每一块都是卡片：卡片本身不是设计，是偷懒的分组；页面没有发丝线、没有留白节奏。
  • 信息权重无差别：维修/回收/购买三块大小一样，等于告诉用户「你自己猜哪个重要」。

二、配色：从「促销橙」换成「工具感的深松绿」

橙色是二手平台的通用色（转转、爱回收），意味着热闹与低价；而 RePhone 要卖的是 「先报价、修好再付、有质检报告」——这是专业与可信，不是折扣。深松绿同时命中三件事： 回收/环保、质检通过、工具与可靠。它也和所有竞品拉开距离。

规则 一屏之内，深绿只出现在头部与选中态， 琥珀只出现在「钱」上，其余全部交给暖白与墨色。颜色越少，越像被设计过。

三、版式：用发丝线和留白，不用卡片和阴影

  • 去掉全部投影，改为 1px 发丝线（#E7E4DC）+ 8~10px 小圆角。硬边比浮起更「专业」。
  • 不用胶囊搜索框，改成一条带下边线的通栏，弱化「App 感」。
  • 故障入口做成描边方框而不是粉彩圆底，图标统一 1.7px 描边墨色。
  • 三业务改成「目录」分栏（01/02/03 + 竖线），比三张并排卡更有秩序，也更省高度。
  • 严选做成「1 张大卡 + 2 行紧凑列表」的不对称结构，而不是三张等宽卡横滑—— 第一件商品值得被放大，其余降级为列表。
  • 回收做成行情表（品牌 / 机型 / 最高价，细线分栏），信息密度高于卡片，符合「比价」心智。
  • 保障降为一行小字，不再占一个宫格区块。

六、落地前需要你知道的两件事

  • 这是全局换肤，不只是首页。深松绿要生效，必须同步改 style/design-tokens.wxss 的 --brand 等令牌，维修/回收/购买/我的 各页都会跟着变。建议单开一个提交做「设计令牌切换」， 再单开一个提交做「首页改版」，这样随时可以回退其中一个。
  • 价格色与品牌色分离是本稿的硬规则：以后任何页面都不允许用品牌绿写价格， 必须用 --money（琥珀）。这条建议写进 AGENT.md 的设计约束。

待你确认 主色方向（深松绿 vs 换深靛蓝）、 是否接受全局换肤、以及首页是否保留「三条路」这个叫法。
