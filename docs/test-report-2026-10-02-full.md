## 6. 缺陷与观察项

### P1-1 停用租户的管理员登录接口仍放行（建议修复）
- **复现**：租户 2 停用后，`POST /api/admin/auth/login`（e2e_tenant_admin）返回 `code=0` + 正常 token + `tenantId:2`；前端随后被守卫弹回登录页（登录「闪退」）。
- **影响**：数据**无泄漏**——该 token 打任何业务接口均被 AdminTokenFilter 拦截：`{"code":40101,"message":"所属租户已停用，请联系平台"}`（第二层纵深防御实测有效）。但登录准入应在此步即拒绝并给出明确文案，而非让用户登录成功后被闪退。
- **修复建议**：登录事务内校验所属租户状态，停用即返回业务错误（如 40104「所属租户已停用」）。涉及 `AdminAuthController.login`（登录准入处一次 tenant status 读取）。
- **证据**：登录响应 JSON（code=0, tenantId=2）+ 两个业务接口 40101 回包；租户已恢复启用。
